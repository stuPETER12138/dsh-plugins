# 便签墙 · Sticky Wall

> 包名 `@local/dsh-sticky-wall` · 版本 1.4.4 · 已在 DSH Desktop 0.2.2-rc.5 上实测启用

DSH Web 左侧栏里的便签墙：灵感来的一瞬间先贴上去，重要的置顶，以后用搜索找回。在会话里选中一段文字，还能把它收藏成书签，按会话索引；点一下书签，就能跳回收藏它的那一轮消息。会话归档后，它的书签自动消失。便签和书签都只保存在本机浏览器里，随开随用。

## 功能

- **左侧栏入口**：侧栏「便签墙」一行，点开是整页便签墙，输入框自动聚焦，可以立刻开始写。
- **会话书签**：在会话里用鼠标选中文字，浮出的操作条上点「收藏」，这段文字就进入便签墙的「书签」列表；普通会话保留原有的「引用文本」按钮，两个操作并排出现。
- **书签索引**：便签 / 书签两个标签页来回切换；书签按会话分组，显示会话标题、数量和第几轮；支持搜索、复制、删除与 6 秒撤销。
- **跳回原文字**：点书签正文（或卡片上的跳转按钮）会打开对应会话，逐层展开折叠的轮次过程、思考/工具组和消息行，把收藏时选中的那段文字滚到视野中央，并只用**黄色定位框**框住它；不附带文字、徽标或按钮，跟随滚动，12 秒后自动消失。浅色模式用深琥珀边框 + 浅黄底，深色模式用亮黄边框 + 浅黄底。如果折叠预览被完整内容替换导致路径失效，就用消息源文本指纹和轮次、前后文、文字一起重新匹配；连原文都找不到时黄色框落在整条消息上，而不是只给一个不明显的行描边。会话标题按钮仍然只打开会话顶部；旧书签没有位置数据时按收藏文字查找，找不到才只打开会话。
- **归档即消失**：书签记住所属会话；会话一旦归档，它的书签会从列表和 localStorage 中删除（撤销归档也不会把书签带回来）。便签墙页面仍打开时底部会提示移除了几条，页面已关闭时直接静默清理。
- **高低错落紧密排列**：每条便签按自身文字高度落在当前最短的一列，长短不一的便签紧密交错成瀑布流，不会像等高网格那样在短便签下面留出空洞；窗口变窄时自动减少列数，窗口拉伸时重新排列。
- **快速记录**：写完按 `⌘/Ctrl + Enter` 保存；空内容时保存按钮禁用；单条上限 4000 字符。
- **六种纸色**：黄、粉、蓝、绿、紫、橙；输入框选中的颜色会被记住，下一次接着用。
- **置顶与排序**：置顶的便签排在最前，其余按最近更新排序（编辑或置顶都会刷新更新时间）。
- **搜索**：按正文做大小写不敏感的子串搜索，带一键清空；没有结果时有单独的空状态。
- **编辑**：双击便签正文或点铅笔按钮进入编辑，可改文字与纸色；`Ctrl + Enter` 保存，`Esc` 取消。
- **复制与删除**：一键把便签正文复制到剪贴板；删除后 6 秒内可在底部提示条上撤销。
- **多窗口同步**：同一浏览器里另一个窗口改了便签，本窗口通过 `storage` 事件自动刷新。
- **主题跟随**：布局、边框、文字全部使用 `--dsw-*` 主题 token，深色主题单独调整便签纸色、边框和投影，切换浅色 / 深色自动适配。
- **中英界面**：文案随 DSH 界面语言切换。

## 使用

1. 左侧栏点「便签墙」打开整页便签墙；顶部显示当前标签页的总数，输入框自动获得焦点。
2. 在「便签」页签的输入框写内容，选一个纸色，按 `⌘/Ctrl + Enter` 或点「保存便签」。
3. 便签按「置顶 → 最近更新」排列，并按各自高度落位：先填满第一行，之后每条都贴到当前最矮的那一列，长短混排也不会留下网格行那样的空白。鼠标悬停在便签上出现置顶、复制、编辑、删除按钮（触屏设备上常显）。
4. 在任意会话里用鼠标选中文字，浮出的操作条点「收藏」；随后回到「便签墙」的「书签」页签，就能按会话分组看到刚才收藏的文字。点书签正文会回到该会话并把选中的那段原文字高亮，点会话标题只打开会话顶部；复制、删除与撤销都在书签卡片上。
5. 用右上角搜索框筛选当前页签，右侧的 × 可以一键清空；切换页签会自动清空搜索词。
6. 删除会立即生效，底部提示条保留 6 秒撤销机会；刷新页面后便签与书签仍然在。会话归档后，该会话的书签会立即消失；便签墙页面还开着时提示条会说明移除了几条。

## 安装

完整的安装、升级与卸载步骤见 [docs/INSTALL.md](../docs/INSTALL.md)；**每个插件单独安装**。本插件常用：

1. **方式 B：从本地文件夹安装（桌面端推荐、可离线）**：DSH Desktop 左侧栏「插件」→ 右上角「添加插件」→ 填本插件文件夹的**绝对路径**（本机为 `D:\github\dsh-plugins\dsh-sticky-wall`）→「安装」→「立即启用」。
2. **方式 A：从插件索引安装**：插件页「发现」标签 →「添加索引源」→ 填 `https://raw.githubusercontent.com/stuPETER12138/dsh-plugins/main/index.json` → 找到本插件 →「安装」→「立即启用」。索引方式**需要本机能访问 GitHub**。
3. **方式 D：命令行（`dsh` CLI profile）**：`dsh plugin --profile <profile> add "link:<本插件绝对路径>"`。DSH 0.2.2 会自动把它写进该 profile 的 `dsh.profile.bundles`，重启 profile 后生效；Desktop 的 `desktop` profile 请用方式 A / B，不要从外部 CLI 改。

也可以直接让 DSH 里的 Agent 安装（方式 C），效果与方式 B 相同。

安装时必须注意：路径必须是**绝对路径**；**每个插件独立安装**，插件之间没有依赖；桌面端请走**插件页**，不要手改 profile 文件。

其他插件与仓库总览见[根 README](../README.md)。

## 验证生效

- 插件页里本插件显示为已启用，没有「不可用」标记；
- 左侧栏出现「便签墙」入口，点击后看到标题、输入框、「便签 / 书签」两个页签与「0 条便签」；
- 写一条便签并保存，出现「已保存」提示和便签卡片；
- 再写几条长短不同的便签，卡片会按列交错紧贴排列（短便签下方不再留出整行空白）；拉宽 / 拉窄窗口，列数与排列随之变化；
- 在会话里选中文字，浮出的操作条同时有「引用文本」和「收藏」；点「收藏」，底部短暂显示「已收藏」，切到「书签」页签能看到按会话分组的卡片；
- 书签卡片显示「第 N 轮」；点书签正文，会话打开后会滚到收藏时的那段文字，只用黄色定位框框住它；浅色 / 深色模式各用一套边框与底色，12 秒后自动消失；
- 归档该会话后，书签从「书签」页签和 localStorage 中消失；
- 刷新页面或重启 DSH，便签与未归档会话的书签仍在。

## 兼容性

- **实测环境**：DSH Desktop 0.2.2-rc.5、Windows 11、Node 24.21.0 / pnpm 11.28.5；插件在本机已启用。
- **运行位置**：纯浏览器侧插件（`dsh.client.platform = web`），依赖客户端模块系统 `window.__ModuleLoader__`、`slots`（`sidebar.panellist`、`main`、`conversation.chat.text-interaction`）、`locale`、`sessions`、`workspaces`、`uiWorkspace` 与 `uiConversation`；Host 半边的 `index.js` 是空实现，只为让 Loader 行存在。书签功能需要 DSH Web 自带的工作区与聊天插件；如果某个 profile 撤掉了这些服务，插件不会激活。
- **浏览器能力**：`localStorage`、`navigator.clipboard`（需要安全上下文，被拒绝时提示「浏览器不允许访问剪贴板」）、`storage` 事件、`ResizeObserver` 与 `color-mix()`。DSH Desktop 自带的 Electron 满足这些要求。
- **平台**：代码里没有平台分支，理论上 Windows / macOS / Linux 的桌面端与浏览器端表现一致；实际只在 Windows 11 上测试过。

## 数据与隐私

- **localStorage 键**：
  - `dsh.sticky-wall.notes.v1`：便签数组，每条 `{ id, text, color, pinned, createdAt, updatedAt }`，`text` 最长 4000 字符；
  - `dsh.sticky-wall.bookmarks.v1`：书签数组，每条 `{ id, text, sessionId, sessionTitle, createdAt, turn?, seq?, nodeKey?, flowKey?, sourceIndex?, sourceHash?, sourceLength?, startPath?, startOffset?, endPath?, endOffset?, offset?, prefix?, suffix? }`；`text` 最长 4000 字符，最多保留 300 条。`turn` 是会话里的轮次，`seq` 是该轮 `turn/start` 的事件序号，`nodeKey` / `flowKey` 是 Chat 消息席位的稳定键；`sourceIndex` 是消息内文本源元素的序号，`sourceHash` / `sourceLength` 是该源文本的指纹与长度（折叠预览被完整内容替换后仍能认出原来的消息源），`startPath` / `endPath` 是从该源元素到选区起止节点的子节点索引路径，`startOffset` / `endOffset` 是节点内偏移，这组字段用于还原精确 DOM Range；`offset` / `prefix` / `suffix` 是文字回退锚点（源文本字符偏移与前后各最多 32 字）。旧书签可以没有这些位置字段；
  - `dsh.sticky-wall.prefs.v1`：`{ color, tab }`，记录输入框上次选的纸色和当前页签。
- **容错读取**：损坏或旧格式的条目会被逐条校正，没有正文（或书签缺少会话 ID）的条目直接丢弃；颜色不合法时回退成黄色，旧版只有 `{ color }` 的偏好仍可读取。
- **归档清理**：监听工作区归档集合；会话归档后删除该会话的全部书签并写回 localStorage。撤销归档不会恢复书签。
- **不联网**：没有网络请求，不与 Host 通信，没有遥测，也不写任何本机文件。
- **剪贴板**：只有点击「复制」时才写入便签正文，不读取剪贴板。
- **数据位置**：存在当前浏览器 profile 的 localStorage 里；换机器、换 profile、清浏览器数据都不会迁移，需要时请手动复制正文备份。

## 工作原理

1. **三个席位**：`sidebar.panellist` 注册 `id: sticky-wall`、`order: 20` 的侧栏行，渲染便签图标；`main` 注册 `key: sticky-wall` 的整页面板，渲染便签墙 / 书签索引；`conversation.chat.text-interaction` 注册浮出的文字操作条。
2. **状态**：`StickyWallPage` 用 `useState` 持有便签列表、输入框纸色、当前页签、搜索词、草稿和编辑态；`notes` / `color` / `tab` 变化时写入 localStorage。书签由模块级的 `bookmarkStore` 持有，页面用 `useSyncExternalStore` 订阅，选中文字的操作条也直接写同一个 store。
3. **读取与校正**：进入页面时 `loadState()` 读便签与偏好两个键，`normalizeNote()` / `normalizeBookmark()` 逐条校正字段；书签另由 `bookmarkStore` 在插件激活时读取并按 `createdAt` 降序排序。
4. **排序与搜索**：便签先按搜索词过滤，再按「置顶优先、同组内 `updatedAt` 降序」排序；书签按正文或会话标题过滤，按会话分组，组内按收藏时间降序，组间按组内最新一条排序。
5. **撤销**：删除便签或书签时把整条记录放进底部提示条的撤销回调，6 秒内点击可放回列表最前面；提示条超时后不再可撤销。恢复书签前会再确认会话没有被归档。
6. **多窗口**：页面监听 `window` 的 `storage` 事件同步便签与偏好；插件的 `apply` 另监听书签键，任何窗口改动书签都会让当前窗口重新读取。
7. **选中文字**：通过 `ctx.uiConversation.interactions.register()` 注册 `sticky-wall-bookmark`；普通会话里由原有的 `quote` 交互打开浮层，本插件用同一个 `quote` 键和更低的 priority 注册一个包含「引用文本 + 收藏」的操作条，因此引用行为保持不变、收藏按钮并排出现；引用不适用（只读子会话等）或没有引用插件时，本插件自己的交互打开只有「收藏」的操作条。右键选中文字是后一种情况的兜底入口，普通会话保留浏览器原生右键菜单。
8. **会话归属与归档**：收藏时从当前 `SessionSnapshot` 取 `sessionId`，用 `ctx.sessions.list` 的 `displayTitle` 记下会话标题；同时从选区所在的 Chat 席位读 `data-chat-turn`、`data-chat-node-key`、`data-chat-flow-key`，再从 `session.projections.faceOf('turnOutline')` 解析该轮的 `seq`（`turnOutline` 不在时留空）。页面和插件级订阅都监听 `ctx.workspaces.list` 的 `archivedSessionIds`。会话一进入归档集合就调用 `bookmarkStore.purge()` 删除它的书签并写回 localStorage：页面打开时由页面清理并在底部提示，页面关闭时由插件级订阅静默清理。
9. **跳回原文字**：点书签正文或跳转按钮 → `uiWorkspace.openSession()` 打开会话 → 轮询 `sessions.binding()` 等到 Chat 的 Session 席位 → 有 `seq` 时调用 `session.loadThrough(seq)` 补齐该轮历史 → 优先找精确 `nodeKey` 的席位（即使它被 `hidden="until-found"` 藏在折叠过程里），依次展开该轮的 `turn-process` 头、`step-process` 组和席位自己的 disclosure 行 → 用 `sourceIndex` / `sourceHash` + `startPath` / `startOffset` + `endPath` / `endOffset` 还原精确 DOM Range；路径失效时用 `offset` / `prefix` / `suffix` 在席位内查找，再退化到全窗口 `[data-text-interaction-source]`，先按源文本指纹、再按轮次、前后文和文字评分匹配 → 用 Range 首行矩形把聊天滚动容器居中到那一段，并在展开布局稳定前多次重新居中 → 在页面上叠加 `.sw-jump-locator` 的黄色 Range 框：没有文字、徽标或按钮，跟随滚动 12 秒后自动消失；没有精确 Range 时框住整条消息。只有完全无法创建定位层时才退回整行描边；连消息都找不到时只完成打开会话。
10. **便签排列**：`useWallMasonry()` 在每次渲染后、浏览器绘制前量出每张卡片的实际高度，把卡片按顺序放到当前最矮的一列（并列时靠左），再把列坐标与墙高直接写到 DOM 上，因此重排不会触发 React 重渲染，编辑中的输入框也不会失焦。`ResizeObserver` 同时盯着墙和每张卡片，侧栏宽度变化、窗口缩放、编辑框长高时都会重新排列；列宽下限与间距由 `.sw-wall` 上的 `--sw-wall-min`（228px，窄屏 200px）与 `--sw-wall-gap`（14px）控制。
11. **样式**：插件向 `document.head` 注入带 `data-dsh-plugin="sticky-wall"` 的 `<style>`，颜色取自 `--dsw-*` 主题 token 或与固定纸色的 `color-mix()`；深色规则挂在 `body[data-ds-dark-theme]` 下。书签卡片沿用便签的纸色混合、圆角、边框和悬停操作条；选中文字的操作条沿用宿主浮动按钮的描边、阴影和圆角。

## 卸载与数据清理

1. 在插件页卸载本插件（或按 [INSTALL.md](../docs/INSTALL.md) 的 CLI 方式移除 `@local/dsh-sticky-wall`）。卸载**不会删除便签**，数据在浏览器里，不在插件目录。
2. 要彻底清理数据，在 DSH 开发者工具里执行：

   ```js
   localStorage.removeItem('dsh.sticky-wall.notes.v1')
   localStorage.removeItem('dsh.sticky-wall.bookmarks.v1')
   localStorage.removeItem('dsh.sticky-wall.prefs.v1')
   ```

3. 先卸载插件再清理也可以；重新安装插件后旧便签与书签仍在，直到你删除这些键。

## 已知限制

- 数据只存在当前浏览器 profile，**不跨设备同步**；没有导出 / 导入界面，需要搬移时请手动复制正文。
- 撤销窗口只有 6 秒；提示条消失或页面刷新后删除即不可恢复。
- 只有纯文本：没有富文本、标签、拖拽排序或分组，单条上限 4000 字符。
- 书签是收藏时的文字快照，不跟随原消息编辑或删除；最多保留 300 条，超出后旧书签会被挤掉。会话归档会永久删除书签，撤销归档不会恢复。
- 书签按会话 ID 归属；同一段文字在不同会话里收藏会得到两条书签，同一会话里重复收藏同一段文字会被去重。
- 1.4.3 之前创建的书签没有 `sourceHash` 和 DOM 路径；它们仍会走自动展开和文字匹配，但同一段文字在消息里重复出现时，删除后重新收藏一次才能写入源指纹，定位最稳。
- 跳回原文字是**尽力而为**：先按保存的 DOM 路径还原精确 Range，路径失效（折叠预览被完整内容替换、消息重新渲染）时依次退回字符偏移/前后文、全窗口文字匹配，并用消息源文本指纹优先认出原来的消息；旧书签没有位置字段时只按文字查找。折叠的思考/工具过程会自动逐层展开，因此可能拉长当前轮并短暂重排。黄色定位框显示 12 秒后自动消失，没有附加文字或关闭按钮；如果收藏的是折叠预览里的文字而完整内容并不包含那段预览，或会话停在「轨迹」等非 Chat 视图、历史页加载失败，就只能在消息层画框或仅打开会话。位置信息依赖 Chat 的 DOM 锚点（`data-chat-*`）与 `turnOutline` 投影，宿主以后改锚点时可能退化到按文字查找或打开会话。
- 搜索是大小写不敏感的简单子串匹配，不支持分词与正则。
- 剪贴板依赖安全上下文与浏览器权限，被拒绝时只能提示失败。
- 便签纸色是固定纸色与主题底色的混合色；在极端自定义主题下对比度可能偏离预期。
- 便签按「当前最短列」落位，底部边缘是参差的（瀑布流的正常取舍）；这是紧密排列的代价，不是缺行。
- 便签数量很多时一次性渲染全部卡片，未做虚拟滚动；排列需要逐张量高，卡片数量极大时首次排列的开销随之增加。书签列表同样一次性渲染。
