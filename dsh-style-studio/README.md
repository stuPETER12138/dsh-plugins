# 风格工作台 · Style Studio

> 包名 `@local/dsh-style-studio` · 版本 2.2.0 · 已在 DSH Desktop 0.2.2-rc.1 上实测启用

左侧边栏新增一页「视觉风格」，用六套手工调色板一键换掉整个 DeepSeek Harness 的外观。每套风格都自带浅色与深色两版，「外观」的浅色 / 深色 / 跟随系统照常工作，风格自动适配。**毛玻璃**主题支持自定义图片背景：图片铺在底层并模糊，磨砂面板浮在上面；背景模糊、雾面浓度、面板浓度三条滑杆实时可调，面板浓度越高面板越实、文字越清晰。

## 六套风格

| 风格 | 名称 | 气质 |
| --- | --- | --- |
| `glass` | 毛玻璃 · Frosted Glass | 现代磨砂面板：半透明表面、小圆角、细描边，配一张自己的图片，界面浮在模糊的背景之上。 |
| `ink` | 水墨书画 · Ink & Brush | 宣纸暖白与墨色文字，朱砂、石绿、赭石相间，通篇霞鹜文楷；深色是砚池夜墨、象牙色字与低饱和朱砂，安静而克制。 |
| `midnight` | 深空极夜 · Midnight Sky | 幽蓝深底与冷冽星辉，深色面板适合夜间使用。 |
| `forest` | 苔原森野 · Moss & Meadow | 苔绿与奶油的自然配色，克制的圆角，像一本林间手账。 |
| `pixel` | 像素街机 · Pixel Arcade | 8-bit 街机配色：霓虹洋红与青蓝、直角边框与硬边投影，像一台老式游戏机的界面。 |
| `mono` | 石墨黑白 · Graphite Mono | 纯黑白灰与利落直角，高对比的极简编辑部风格。 |

## 为什么从「设置」搬到左侧边栏

1.x 版本把入口放在「设置 → 通用设置」里的一行，因为那时第三方设置分区 id 会回落到「通用设置」的齿轮图标。2.0 起改用**侧边栏面板**这一等公民席位：

- **入口更好找**：和「便签墙」「用量统计」一样，侧栏出现一个调色板图标，点开就是整页设置，不再需要先打开设置弹窗；
- **空间更充裕**：整页可以放六张带缩略预览的风格卡片、背景图拖放区、背景选择与三条滑杆，设置弹窗里的单行放不下这些；
- **可折叠**：侧栏收起时它和其它面板一样变成一个图标，`Esc` / 折叠不会丢状态。

## 功能

- **侧栏页面入口**：`sidebar.panellist`（`id: style-studio`，`order: 40`）提供图标与本地化名称，展开时显示「视觉风格」，收起时是带 tooltip 的调色板图标；页面本身注册在布局的 `main` 槽，键同为 `style-studio`。
- **六套完整调色板**：每套含 36 个颜色（浅色 / 深色各一套）与 13 项与配色无关的语言（字体、圆角、阴影、菜单模糊）。毛玻璃以「底色半透明 + 面板接近实心」为原则（卡片、输入框、气泡、侧栏都在 90% 以上不透明度），水墨书画另有单独的深色阴影档，像素街机使用 0 圆角与硬边位移阴影。
- **风格卡片**：每张卡片带一个迷你窗口预览（侧栏条、文字行、强调色），并按当前浅色 / 深色自动切换预览配色；选中态有勾选角标与 `aria-pressed`。
- **毛玻璃背景**：拖入或选择本地图片，立即铺满整个应用底层；内置「雾蓝 / 暖沙 / 暮青」三张低对比背景在没有图片时兜底；背景模糊 0–40px、雾面浓度 0–80%、面板浓度 60–100% 三条滑杆实时生效，页面里的预览区会同步显示模糊与雾面效果。选图后自动切到毛玻璃并提示；移除图片后 8 秒内可以「撤销」。
- **覆盖面广**：一次改写 110 个宿主 token——`--dsw-alias-*`、`--dsw-specific-*`、代码块与行内代码、滚动条、菜单材质、toast、开关滑块、思考过程渐隐、字体、圆角与三级阴影。面板、会话、输入框、菜单、对话框以及任何基于 token 的插件都会跟着变。
- **浅深自适应**：风格只提供调色板，「外观」仍掌握浅色 / 深色 / 跟随系统的决定权；图片背景在深色下会自动压暗，雾面颜色换成深色。
- **恢复默认**：「主题」卡片右上角的「恢复默认外观」清除当前风格回到原生外观；「毛玻璃背景」卡片右上角的「恢复默认背景」把背景、模糊、雾面、面板浓度与图片一起复位。
- **记住选择**：风格与背景参数保存在 localStorage，图片保存在 IndexedDB，刷新或重启后在同一个浏览器里自动恢复。
- **中英界面**：页面文案、风格名称与说明随 DSH 界面语言切换。

## 毛玻璃背景怎么用

1. 打开侧栏的「视觉风格」，点选「毛玻璃」卡片（或者直接在背景卡片里点「切换到毛玻璃」）。
2. 把一张图片拖到背景预览区，或点「选择图片」从磁盘挑选；支持 PNG、JPEG、WebP、GIF、AVIF，单张上限 24 MB。选好会自动切到毛玻璃并提示；超过 2048px 的长边会先缩小再保存（见[性能](#性能)），动图只保留首帧。
3. 用「背景模糊」调节底图虚化（默认 18px），用「雾面浓度」调节盖在底图上的雾面（默认 38%），用「面板浓度」调节卡片、输入框、气泡与侧栏的实心程度（默认 100%，即最清晰）。
4. 想让图片更明显：把面板浓度调低到 80–90%，或降低雾面浓度；想让文字更清晰：把面板浓度调到 100%、雾面保持在 35% 以上。觉得组件后面透出的文字碍眼时，优先调高面板浓度。
5. 不想用图片时点「移除图片」，会退回下面选中的内置背景（状态栏会留 8 秒「撤销」）；背景也可以单独换。
6. 图片按 `cover` 铺满视口，不裁切保存，换窗口尺寸会自动重新铺排。
7. 处理大图时按钮会暂时禁用，状态栏显示「正在处理图片…」，避免连续操作互相打断。

## 性能

毛玻璃的观感靠两层全屏效果（底图模糊 + 雾面），很吃 GPU。2.2 针对这条链路做了四项优化：

| 优化 | 做法 | 收益（按 1920×1080 视口估算） |
| --- | --- | --- |
| 底图降采样 | 长边超过 2048px 或大于 1.2 MB 的图片，先缩放到 2048px 再存成 WebP | 4K 照片的像素数从约 1200 万降到约 280 万，解码、显存与首帧都更快 |
| 模糊层半分辨率 | 底图只铺 54% 视口、模糊半径减半，再放大 2 倍覆盖屏幕 | 需要模糊的像素约为原来的 1/4，模糊层重绘更快、纹理更小 |
| 滑杆合帧 | 拖动滑杆时把 body 变量写入与 React 更新合并到一帧（`requestAnimationFrame`），值没变就不写 | 每秒最多 60 次，避免一帧内多次全文档样式重算 |
| 风格卡 memo 化 | 六张风格卡用 `React.memo`，点击回调提到模块级 | 拖动滑杆时只重绘背景卡片，不重绘 12 个缩略图 |

另外：切换风格时才重新注册 110 个 token，平时不重复计算；动图（GIF）会保存成静态首帧——全屏动图会持续解码与合成，是这条链路上最费电的做法。旧版本存下的大图会在下一次加载时自动缩小并回写，不必重新选图。

以上为像素数与调用次数层面的估算，未在做帧率 / GPU 计时实测；实际流畅度取决于显卡与显示器分辨率。

## 使用

1. 点左侧栏的调色板图标打开「视觉风格」。
2. 在「主题」里点任意风格卡片，整个应用立即换肤；鼠标悬停卡片可以看到该风格的完整说明。
3. 想还原外观时点「主题」卡片右上角的「恢复默认外观」。
4. 浅色 / 深色 / 跟随系统仍由「设置 → 外观」控制，风格跟着自动适配。
5. 想用自定义背景：选「毛玻璃」，然后拖入图片、调两条滑杆即可。

## 与「外观」的关系

「外观」仍拥有浅色 / 深色 / 跟随系统的决定权，「视觉风格」只决定配色、字体、圆角与阴影的语言，两者正交：水墨书画 + 深色 = 砚池夜墨；像素街机 + 浅色 = 米白纸面与 8-bit 强调色；毛玻璃 + 深色 = 深色磨砂面板压在压暗的底图上。风格不会改写「外观」的选择，也不会写进 DSH 配置。

## 安装

完整的安装、升级与卸载步骤见 [docs/INSTALL.md](../docs/INSTALL.md)；**每个插件单独安装**。本插件常用：

1. **方式 B：从本地文件夹安装（桌面端推荐、可离线）**：DSH Desktop 左侧栏「插件」→ 右上角「添加插件」→ 填本插件文件夹的**绝对路径** →「安装」→「立即启用」。
2. **方式 A：从插件索引安装**：插件页「发现」标签 →「添加索引源」→ 填 `https://raw.githubusercontent.com/stuPETER12138/dsh-plugins/main/index.json` → 找到本插件 →「安装」→「立即启用」。索引方式**需要本机能访问 GitHub**。
3. **方式 D：命令行（`dsh` CLI profile）**：`dsh plugin --profile <profile> add "link:<本插件绝对路径>"`。DSH 0.2.2 会自动把它写进该 profile 的 `dsh.profile.bundles`，重启 profile 后生效；Desktop 的 `desktop` profile 请用方式 A / B，不要从外部 CLI 改。

也可以直接让 DSH 里的 Agent 安装（方式 C），效果与方式 B 相同。

安装时必须注意：路径必须是**绝对路径**；**每个插件独立安装**，插件之间没有依赖；桌面端请走**插件页**，不要手改 profile 文件。

## 兼容性

- **实测环境**：DSH Desktop 0.2.2-rc.1、Windows 11、Node 24.21.0 / pnpm 11.28.5；插件在本机已启用。
- **用到的扩展点**：`ctx.theme.overrideTokens(source, layer)` 主题覆盖层与 `theme/change` 事件、`slots`（`sidebar.panellist` + `main`）、`locale`；浏览器侧声明 `inject = ['slots', 'locale', 'theme']`，`package.json` 的 `dsh.client.inject` 只用于排序主题 / 侧栏 / 布局 / 语言的模块加载；Host 半边 `index.js` 是空实现。
- **CSS 能力**：`color-mix()`、`body[data-ds-dark-theme]` 深色标记、`body::before/::after` 固定背景层与 `filter: blur()`；DSH Desktop 自带的 Chromium 满足要求。
- **平台**：覆盖层、body 属性与 IndexedDB 都是 Web 前端机制，Windows / macOS / Linux 的桌面端与浏览器端理论上一致；实际只在本机 Windows 11 上测试。

## 数据与隐私

- **localStorage**：
  - `dsh.style-studio.v1`：当前风格 id 的原始字符串（`glass` / `ink` / `midnight` / `forest` / `pixel` / `mono`），恢复默认时删除；
  - `dsh.style-studio.glass.v1`：背景参数 JSON，例如 `{"gradient":"aurora","blur":18,"haze":38,"density":100}`（`density` 为面板浓度百分比）。
- **IndexedDB**：数据库 `dsh-style-studio`，对象仓库 `wallpaper`，固定键 `current`，值是 `{ blob, name, size, width, height, addedAt }`；长边超过 2048px 或大于 1.2 MB 的图片会先缩放并重编码为 WebP（小图原样保存，均不裁切），`size` 记录的是实际保存的字节数。移除图片或点「恢复默认背景」时删除记录（移除后的 8 秒撤销期内记录先保留，撤销窗口结束才真正删除）。
- **只在本机**：不上传、无遥测、不写本机文件、不与 Host 通信；图片只在浏览器渲染背景时使用。
- **不改动宿主**：切换风格只做四件事——设置 `document.body` 的 `data-dsh-style` 属性、注入插件自己的样式表、在内存里注册 / 释放 token 覆盖层、在 body 上写背景相关自定义属性；不修改 DSH 源码、配置文件或「外观」偏好。

## 工作原理

1. **侧栏入口**：向 `sidebar.panellist` 注册 `id: style-studio`、`order: 40` 的图标，`label` 提供展开行文字与折叠 tooltip；页面向布局的 `main` 槽注册同键页面，布局负责选中态与面板切换。
2. **调色板**：`COLOR_KEYS` 的 36 个颜色键与 `COMMON_KEYS` 的 13 个语言键会转成 `--dsh-style-*` 自定义属性；六套 `PRESET_SPECS` 各带 `light`、`dark` 与 `common`，毛玻璃与水墨书画另带 `commonDark`。加载时 `assertPreset()` 校验缺键并直接抛错，避免悄悄渲染出坏配色。
3. **变量层**：插件样式表为每套风格生成两条规则——`body[data-dsh-style="<id>"]` 声明浅色调色板，`body[data-dsh-style="<id>"][data-ds-dark-theme]` 声明深色调色板（以及可选的深色阴影）。毛玻璃的 36 个颜色写成带 alpha 的 `rgb()`，alpha 再乘上 `var(--dss-glass-alpha)`：面板浓度 100% 时卡片 / 输入框 / 气泡是 92–98% 不透明的实心磨砂面板，只有页面底色保留 48% 半透明让底图透出；把面板浓度调低才会整体变透。
4. **token 层**：110 个宿主 token 由 `overrideTokens` 映射到 `var(--dsh-style-*)`；其中 68 个是直投，42 个是组合值（`color-mix()`、`linear-gradient()`，以及用 `var(--dsh-font-family-text, …)` 包一层以保证用户自选字体优先）。同一表达式同时用于浅色和深色，最终颜色由调色板变量决定。
5. **背景层**：`body[data-dsh-style="glass"]::before` 只铺视口的 54%，模糊半径取 `blur / 2`，再用 `transform: scale(2)` 放大覆盖屏幕——屏幕上看到的模糊仍是设定值，但参与高斯模糊的像素只有约 1/4。`::after` 是随浅 / 深切换颜色的雾面。底图变量由页面写到 `document.body.style` 上，渐变则由 `data-dss-bg` 属性选中对应规则。
6. **图片流水线**：选图后用 `createImageBitmap` 解码，长边超过 2048px 或文件大于 1.2 MB 时画到 canvas 上缩放并编码为 WebP，再写入 IndexedDB（记录 Blob、尺寸与字节数）；`URL.createObjectURL()` 生成背景地址，启动时读出记录并恢复，卸载时 `revokeObjectURL()` 释放。
7. **调参节流**：拖动滑杆时 `updateGlass()` 只把新值记到内存并预约一个 `requestAnimationFrame`，同一帧内的多次输入合并成一次 body 变量写入 + 一次 React 更新；写入前再比对签名，值没变就完全不碰 body，避免无谓的全文档样式重算。持久化另外做 300ms 去抖。
8. **切换**：`applyStyle()` 写入 body 属性 → 重新注册同一个 source 的覆盖层（旧层被替换，只发一次 `theme/change`，JS 主题消费者与主题色元数据随之更新）→ 持久化选择 → 通知订阅者刷新卡片选中态与背景预览。
9. **恢复默认**：删除 body 属性并释放覆盖层，宿主原生 token 立即生效；「恢复默认背景」另外清空图片记录与滑杆参数。
10. **卸载 / 禁用**：插件注册的清理函数会释放覆盖层、取消待执行的动画帧、清掉 body 属性与背景自定义属性、撤销图片 URL，样式表随插件移除，外观即时恢复原生。

## 实现取舍

- **走主题覆盖层，不改宿主**：`overrideTokens` 是 DSH 公开的主题接缝；覆盖层释放后原生 token 立即回来，禁用或卸载插件不会留下痕迹。
- **调色板是数据**：六套风格只是 `light` / `dark` / `common`（+ 可选 `commonDark`）几个对象，新增风格只需要加一段数据，不用改渲染逻辑。
- **用侧栏面板，不新增设置分区**：侧栏面板是 DSH 公开的「全局面板」席位，图标、选中态、折叠与 tooltip 都由宿主负责；页面自己只画内容。
- **背景用 body 伪元素，不插 DOM**：整个背景只是两条 CSS 规则加四个自定义属性（底图、模糊、雾面、面板浓度），不往 `document.body` 里塞节点，卸载时删属性即可干净复原。
- **像素让步给可读性**：底图只铺半分辨率、模糊半径减半再放大，肉眼等价但省下约 3/4 的模糊像素；图片落库前先降到 2048px，避免一张 4K 照片常驻显存。
- **图片进 IndexedDB，不进 localStorage**：localStorage 只有约 5 MB 且只能存字符串；IndexedDB 可以原样存 Blob，配额大得多，也免去 base64 膨胀。
- **一次原子切换**：切换风格只写一个 body 属性和一层 token，宿主只收到一次 `theme/change`，避免逐 token 刷新造成的闪烁。
- **校验前置**：`assertPreset()` 在加载时就检查 36 个颜色键（浅 / 深各一套）与 13 个语言键，缺一个就抛错，而不是渲染出一半的配色。

## 卸载与数据清理

1. 在插件页卸载本插件（或按 [INSTALL.md](../docs/INSTALL.md) 的 CLI 方式移除 `@local/dsh-style-studio`）。卸载会自动撤销 token 覆盖层、body 属性、背景层与图片 URL，界面回到原生外观；侧栏入口与页面同时消失。
2. 如需清除记住的选择与背景图片，在 DSH 开发者工具里执行：

   ```js
   localStorage.removeItem('dsh.style-studio.v1')
   localStorage.removeItem('dsh.style-studio.glass.v1')
   indexedDB.deleteDatabase('dsh-style-studio')
   ```

   不清除的话，重新安装插件后会自动恢复上次的风格与背景。
3. 插件不写任何本机文件或配置，卸载后没有其他残留。

## 已知限制

- **首屏闪一下原生配色**：刷新时宿主启动脚本不认识第三方调色板，要等客户端插件加载后才应用风格，这一瞬间是原生外观，属预期行为。
- **背景图晚一帧出现**：图片存在 IndexedDB，页面加载后异步读出才会铺上；在此之前毛玻璃主题显示内置背景。
- **背景只在毛玻璃主题下显示**：其它风格仍用各自的实色底色，背景参数会被保留，切回毛玻璃即恢复；有图片时用图片，内置背景只在没有图片时生效。
- **面板浓度是全局倍数**：它同时缩放卡片、输入框、气泡、侧栏与页面底色的 alpha，所以调到很低（< 70%）时整套界面都会重新变透、组件后面的文字会透出来；默认 100% 是为可读性选的保守值。
- **移除图片有 8 秒撤销期**：8 秒内点「撤销」可恢复；窗口过去后记录才会从 IndexedDB 真正删除，此时只能重新选图。
- **模糊是 CSS `filter`**：大面积高斯模糊交给 GPU 合成，模糊值调到 40px 时在很低端的集显上可能有额外开销；卡顿就调低「背景模糊」。
- **图片会降采样**：长边超过 2048px 或大于 1.2 MB 的图片会缩放并转成 WebP 再保存，动图只保留首帧。底图本来就被模糊，肉眼几乎无差别，换来的是更小的显存与更快的首帧；需要原图时重新选图即可，插件不保留原始文件。
- **macOS 侧栏例外**：macOS 桌面端侧栏有一层宿主硬编码的渐变底色（`ui-layout`），不经过主题 token，任何风格都改不到；其余界面正常。本仓库未在 macOS 上实测，此条来自开发记录。
- **自定义字体优先**：用户在「外观」里选过字体时，风格里的文字与代码字体让位（宿主 token 用 `var(--dsh-font-family-text, …)` 包装）；水墨书画与像素街机只在没设自定义字体时才改变正文与代码字体。
- **字体回退**：毛玻璃使用系统 UI 字体（SF Pro / Segoe UI Variable / 苹方 / 微软雅黑），水墨书画首选霞鹜文楷，像素街机首选 Cascadia Mono / Code；机器上没装时回退到系统字体，观感会有差别。
- **第三方插件内联颜色改不到**：硬编码颜色（而不是用 `--dsw-*` token）的界面元素不会跟随风格。
- **不改外观偏好**：风格切换不修改「外观」的浅 / 深设置，也不写入 DSH 配置；它只影响当前浏览器。
- 六套调色板与三套内置背景均为原创配色，插件不含图片或字体文件。

## 常见问题

- **侧栏找不到入口？** 确认插件已启用并刷新页面；侧栏折叠时它是图标，展开后才是「视觉风格」。
- **刷新后先闪一下原生配色？** 是预期行为：宿主启动脚本不知道第三方调色板，要等客户端插件加载完才应用。
- **换了风格但字体没变？** 先在「外观」里确认没有设置自定义字体；自定义字体优先于风格字体。
- **背景图不见了？** 它只在「毛玻璃」主题下显示；另外浏览器若禁止 IndexedDB（隐私模式等），图片只在本次会话有效。
- **组件后面透出文字、看不清？** 把「面板浓度」调到 100%（默认值）。它控制卡片、输入框、气泡与侧栏的实心程度；调低会让图片更明显，但滚动内容也会透到面板上。
- **图片太大存不下？** 单张上限 24 MB；超出会提示「图片太大」。换小图，或先压缩再选。
- **大图被压缩会不会糊？** 只在长边超过 2048px 时缩放，而且底图上还盖着 18px 模糊与雾面，肉眼几乎看不出来；换来的是更小的显存与更快的启动。
- **卸载后界面会恢复吗？** 会。覆盖层、body 属性与背景变量都在插件清理函数里释放，样式表也随插件移除。
