# 手柄与语音 · Controller & voice

> 包名 `@local/dsh-gamepad-voice` · 版本 1.1.0 · 已在 DSH Desktop 0.2.2-rc.5 上实测

DSH Web 左侧栏里的手柄与语音面板：按 **Xbox One 键位**操作 DSH，每个动作都标注对应按键；按住 Y 说话代替打字。转写由 DSH 的「语音输入」插件在本机完成，音频不会上传。

## 功能

- **左侧栏入口**：侧栏「手柄与语音」一行，点开是整页控制面板；手柄在任何面板下都生效，不要求停在这一页。
- **Xbox One 键位标识**：A/B/X/Y 用 Xbox One 面板键的四种颜色显示，LB/RB、View、Menu、十字键都按 Xbox One 名称标注；每个动作行、语音按钮和转写设置前都带对应按键图标。
- **按键提示条**：连接手柄时，窗口左下角显示一张紧凑的 Xbox One 按键提示，列出 A/B/X/Y、LB/RB、十字键、View/Menu 的功能；可在页面开关。
- **游戏手柄映射**（Xbox One 标准映射）：

  | 按键 | 动作 |
  | --- | --- |
  | 十字键 ↑ / ↓ | 上一个 / 下一个会话（按住连续切换） |
  | 十字键 ← / → | 上一个 / 下一个左侧栏面板（按住连续切换） |
  | A | 发送当前会话的草稿（等同按 Enter） |
  | B | 停止正在生成的回复；录音时改为取消本次录音 |
  | X | 新建会话 |
  | Y | 按住说话，松开转写；录音时按 A 提前结束并转写 |
  | LB | **按住约半秒**切换转写去向：插入当前草稿 / 直接发送（短按只提示，不切换） |
  | RB | 循环识别语言（跟随语音输入设置 → 引擎支持的语言） |
  | View | 返回对话 |
  | Menu | 打开 / 关闭本页 |
  | LT / RT / LS / RS | 未使用 |

- **按住说话**：麦克风录音 → 按 16 kHz 单声道 WAV 交给本机 SenseVoice → 文字默认插入当前会话草稿（追加在已有草稿之后）；按住 LB 半秒可切换成直接发送。
- **转写后仍可修改**：最近一次转写会留在本页面并标明「已插入当前草稿 / 已发送」，可以先改错字，再按「再次插入」或「再次发送」；只有在插入/发送成功后按钮旁边的提示才会变化，失败时文字不会丢。
- **帧级 HUD**：录音计时与电平、转写中、失败原因、插入结果都以一条轻量提示条显示在窗口底部；停在对话页也能看到。
- **不打断输入**：插入草稿走 DSH 的草稿初始化接口（`whenDraftExists: append`），不会覆盖你已经在输入框里写的文字；输入框正在发送时，转写只留在本页面，不会丢失。
- **录音有安全边界**：窗口失去焦点、页面切到后台、手柄断开或按 Esc 时都会结束当前录音（前三种会继续转写，Esc 直接取消）；不会让麦克风一直开着。
- **可关闭**：页面上可一键关闭手柄控制；关闭后手柄按键不触发任何操作。DSH 窗口失去焦点时手柄操作也会暂停，避免切到游戏时误触。
- **中英界面**：文案随 DSH 界面语言切换；设置保存在本浏览器，刷新后保留。

## 使用

### 手柄

1. 用 USB 或蓝牙连接 Xbox One 手柄，按一下任意键；页面「手柄控制」区块会显示手柄名称与「使用中」，顶部徽标变为「Xbox One 已连接」。
2. 需要换手柄时，在列表里点另一个手柄的「使用」。
3. 目标窗口是 DSH 本身：手柄操作只在 DSH 窗口获得焦点时触发。如果 Windows 设备管理器里能看到「Xbox 游戏设备」，但页面一直显示未连接，把窗口切到前台再按一次 Xbox 键或任意键。

### 语音输入

1. 先确认「插件」页里 **语音输入** 已启用。它提供本插件使用的转写服务；如果从未用过，第一次需要在该插件详情页点「下载并准备」，等待 SenseVoice 模型下载完成。
2. 模型显示 **「已就绪（按需加载）」也是可用状态**：文件已经在磁盘上，第一次转写时才加载进内存，不需要再点「准备语音模型」。
3. 第一次使用语音时，允许系统 / 浏览器让 DSH 使用麦克风。页面上的「请求麦克风权限」按钮会主动请求一次权限并显示结果。
4. 按住手柄 Y（或在页面里按住「按住说话」），说完松开：出现「正在转写…」，随后文字插入当前草稿，窗口底部会提示插入结果。
5. 想直接发出：在页面里把「转写后」切成「直接发送」，或者**按住 LB 约半秒**切换；之后每次转写都会作为一条消息进入当前会话。
6. 想换识别语言：页面下拉框选择，或按 RB 循环切换。选择「跟随语音输入设置」时使用语音输入插件自己的语言设置。
7. 页面会显示「语音可用 / 语音待准备」等状态；不可用时给出「打开插件页」或「准备语音模型」按钮，不会让你对着一个不会工作的按钮说话。

### 页面里的其他操作

- 顶部徽标显示手柄、语音与转写去向；「当前会话」一行显示会话标题与是否正在回复。
- 「最近一次转写」下方的按钮可以再次插入、发送或清空这段文字。
- 语音引擎显示「模型未准备」时，页面会提供「准备语音模型」按钮，不用再去翻插件页。
- 「手柄控制」里的「显示按键提示条」控制窗口左下角的 Xbox One 按键提示，默认开启。

## 语音或手柄不工作时

按下面顺序检查，通常一两步就能定位：

1. **确认页面是新版**：顶部应显示「Xbox One 已连接」、语音按钮里有 Y 图标、窗口左下角有按键提示条。如果还是旧界面，刷新页面（Ctrl+R）；仍不更新就重启 DSH Desktop。
2. **手柄**：页面「手柄控制」是否显示手柄名称？没有的话，确认 Windows 设置 → 蓝牙和其他设备里出现「Xbox 游戏设备」，并点一下窗口让 DSH 获得焦点后按任意手柄键。Xbox One 手柄建议先用 USB 线直连排查。
3. **麦克风**：页面「麦克风」一行是否显示「已授权」？显示未授权时点「请求麦克风权限」，在系统弹窗里允许 DSH；Windows 设置 → 隐私和安全性 → 麦克风也要允许桌面应用访问。
4. **语音引擎**：页面「识别引擎」一行应显示 `SenseVoiceSmall (INT8) · 已就绪（按需加载）` 或「模型就绪」。显示「模型未准备」时点「准备语音模型」；显示「语音不可用」时点「打开插件页」启用「语音输入」。
5. **按住 Y 没反应**：先看页面「实时输入」是否出现 Y；出现说明手柄已连上，再看顶部徽标是否「语音可用」。如果 HUD 显示「语音引擎还没准备好」，按第 4 步处理。
6. **有 HUD 但没有文字**：HUD 会显示「没有识别到语音」或「转写失败: …」；把这句话贴给 DSH，或打开浏览器开发者工具（Ctrl+Shift+I）看 Console 里 `gamepad-voice` 相关错误。

## 安装

每个插件独立安装。完整安装 / 升级 / 卸载步骤见 [docs/INSTALL.md](../docs/INSTALL.md)。

**方式 B：从本地文件夹安装（桌面端推荐、可离线）**

1. DSH Desktop 左侧栏 **插件** → 右上角 **添加插件**。
2. 填入本插件文件夹的**绝对路径**（例如 `<你的仓库路径>\dsh-gamepad-voice`）→ **安装** → **立即启用**。
3. 刷新一次 DSH 页面（客户端模块在页面加载时注入）；左侧栏出现「手柄与语音」入口。

**方式 A：从插件索引安装**：在插件页「发现」标签添加本仓库索引 `https://raw.githubusercontent.com/stuPETER12138/dsh-plugins/main/index.json`，找到本插件安装；需要本机能访问 GitHub。

**方式 C：让 DSH 里的 Agent 安装**：在对话里说「把 `<绝对路径>\dsh-gamepad-voice` 安装到当前 profile 并启用」。

**方式 D：命令行（`dsh` CLI profile）**：

```powershell
dsh plugin --profile <profile> add "link:<本插件绝对路径>"
```

桌面端建议用方式 A / B，由桌面端自己管理依赖；不要手改 profile 文件。

## 验证生效

- 插件页里本插件显示为已启用，没有「不可用」标记。
- 左侧栏出现「手柄与语音」入口，点开后按「语音输入 → 手柄控制 → 怎么用」排列；语音未就绪时先显示「准备语音模型」或「打开插件页」，就绪后才显示可用的「按住说话」。
- 连接手柄并按任意键：页面显示手柄名称，「实时输入」在按键时出现对应按键名；按键映射默认折叠为「按键映射 · 12」。
- 按十字键可以切换会话 / 面板，按 A 能发出草稿，按 B 能停止回复。
- 按住 Y 说一句话再松开：窗口底部出现「正在听写…」与计时，随后出现「已插入当前草稿」，对话输入框里出现识别文字；页面「最近一次转写」里也会标明已处理，可改完再次插入。
- 刷新页面后，手柄开关、转写去向、识别语言仍保留。

## 兼容性

- **实测环境**：DSH Desktop `0.2.2-rc.5`、Windows 11、Electron 44（Chromium 自带 Gamepad API、MediaRecorder、Web Audio）。
- **运行位置**：纯浏览器侧插件（`dsh.client.platform = web`）。依赖客户端模块系统、`sidebar.panellist` / `main` / `shell.overlay` 插槽，以及 `locale`、`sessions`、`conversation`、`uiWorkspace`、`layout` 服务；Host 半边 `index.js` 是空实现，只为让 Loader 行存在。
- **语音依赖**：转写调用 DSH 可选插件 **语音输入**（`@deepseek-ai/dsh-experimental-voice-input-bundle`）挂载的 `remote.speech`。禁用该插件后，手柄控制仍可用，语音区会显示「语音输入不可用」。
- **手柄**：使用 Gamepad API 的标准映射（Xbox One 布局）。标注为非标准映射的手柄按键位置可能不同；DSH 窗口失焦、或被其他程序独占手柄时不触发。
- **平台**：代码里没有平台分支，Windows / macOS / Linux 桌面端理论一致；实际只在 Windows 11 上验证。

## 数据与隐私

- **不联网**：插件本身没有网络请求。录音只通过 DSH 的本地 Remote 交给本机 Host 的 SenseVoice 转写，不上传、不写入磁盘，转写完成后不再保留音频。
- **localStorage 键**：`dsh.gamepad-voice.settings.v1`，内容为 `{ enabled, delivery, language, padId, legend }`；没有任何会话内容。
- **会话数据**：只调用公开的客户端服务——切换会话 / 面板、提交草稿、取消回复、初始化草稿。转写文字进入当前会话的效果与手动输入相同，是否发送由你选择。
- **麦克风**：只在按住说话、或点「请求麦克风权限」时打开；松开、取消、失焦或手柄断开即释放。
- **不修改 DSH 自身文件**，也不访问用户的 profile 或设置。

## 工作原理

1. `apply()` 注册语言包与插槽，并创建运行时；运行时用 `requestAnimationFrame` 轮询 `navigator.getGamepads()`，按边沿与长按重复规则把按键映射到 DSH 客户端服务。
2. 按住 Y 时用 `getUserMedia` + `MediaRecorder` 录音；松开后用 `decodeAudioData` 解码，再用 `OfflineAudioContext` 重采样成 16 kHz 单声道 PCM16 WAV，Base64 后调用 `ctx.remote.speech.transcribe()`。
3. 转写结果默认通过 `conversation.input.requestDraftInitialization(binding, { prompt, whenDraftExists: 'append' })` 追加到当前会话草稿；「直接发送」则调用当前会话作用域的 `conversation.send()`。
4. 页面与 HUD 都只是插槽组件，状态来自插件内部的小型 store；音频与手柄逻辑不依赖页面是否打开。

## 卸载

1. 左侧栏 **插件** → 已安装插件里找到「手柄与语音」→ 停用或移除。
2. 刷新页面；左侧栏入口与窗口底部提示条消失。
3. 本插件的设置保存在浏览器 localStorage 的 `dsh.gamepad-voice.settings.v1`，需要时可在开发者工具里删除；不删除也不影响 DSH。
4. 语音模型属于「语音输入」插件，卸载本插件不会删除它。

## 已知限制

- 手柄操作依赖 Gamepad API 的标准映射；个别手柄（或通过 Steam Input 等中转）可能报告不同的按键编号。
- 按键映射固定为页面列出的 Xbox One 布局，暂不支持自定义重映射；录音进行中 A/B 的含义会临时变成「结束并转写 / 取消本次录音」。
- 左下角的按键提示条是窗口悬浮层，窗口很窄时可能与侧栏底部内容重叠；可在页面「手柄控制」里关闭。
- A 会直接发送当前草稿，X 会直接请求新建会话；不需要这些动作时可以在页面上关闭手柄控制。
- 语音转写依赖「语音输入」插件及其模型；第一次使用可能需要下载模型。
- 识别质量取决于 SenseVoice 与麦克风；本插件不做降噪以外的音频处理，也不支持自定义词表。
- 转写默认自动插入或发送，然后仍留在页面里供再次编辑；它不是「先确认再发送」的审阅流程。
- 转写只追加到当前草稿或直接发送，不会自动润色、翻译或整理成列表。
