# 视觉设计基线

本仓库的界面按 [kill-ai-slop](https://github.com/yetone/kill-ai-slop) 的判定来维护：问题不是"不够好看"，而是没做决定的默认值堆在一起。这份文档记录四个插件共同遵守的规则，以及每轮设计清理中保留了什么、为什么。

## 规则

1. **颜色只有一个强调色。** 只用 `--dsw-*` 主题令牌；操作和链接用 `--dsw-alias-state-business-primary`，主按钮用 `brand-primary`。状态色只给真实状态，不当分类色用。
2. **层级来自字号和留白。** 页面标题 22/600，区块标题 14–15/600，正文 13–14，辅助信息 11–12；数字用 `tabular-nums`。正文与标题至少差 1.3 倍。
3. **圆角是一套小尺度。** 4 / 8 / 12 / 16（`--dsw-radius-xs/sm/md/lg`）。开关滑块、spinner、状态点保持圆形；按钮、输入框、卡片不再用 999px 或 14–22px 的"药丸半径"。
4. **边界优先于高度。** 分隔用 0.5–1px 发丝线；阴影只给真正浮起来的层（toast、菜单、对话框），悬停不投影、不发光。
5. **间距按关系分组。** 标题与自己的正文 4–6px，组与组 20–24px，区块之间 16px；不再全页一个 `gap` 值。
6. **动效只说明状态。** 过渡只作用于 background / border / color / opacity，120–150ms；不做悬停位移、放大、脉冲、发光。
7. **图标要携带信息。** 16px 线性图标继承文字颜色，不加圆角色块底；只起装饰作用的图标删除。
8. **文案写具体的事。** 不用 emoji、三段式排比、破折号戏剧化；空状态说明下一步做什么，隐私说明说清楚数据去了哪里。
9. **页面背景是平的。** 不用渐变给界面制造"氛围"，背景只作为内容的一部分出现。

## 各插件落点

- **dsh-completion-notify**：设置行沿用宿主 General 行的字号与间距；测试按钮收为 26px 高、8px 圆角；文案补上"出错"状态，去掉只对 Windows 成立的措辞。
- **dsh-sticky-wall**：删掉副标题与计数药丸；便签用 10–15% 纸色混色 + 发丝边，取消顶部 3px 色条、悬停位移与阴影；色板从圆形点改成方形纸片；空状态去掉大图标；toast 改用宿主 toast 令牌。
- **dsh-usage-stats**：hero 改为平面发丝卡片；KPI 去掉图标色块与每张卡上的 scope 药丸；delta 去掉药丸底色；时间线的四段改成单色阶（蓝 → 灰），成本环用同一色阶；移除扫描脉冲，live 只留 4px 平点；骨架屏去掉 shimmer；供应商的四个事实卡合并为一条分隔带。
- **dsh-session-share**：角色标签从蓝/绿药丸改成 11px 文字；图片计数去掉 emoji，改成本地化文案；按钮与格式切换统一到 4/8px 圆角；当前格式不再用阴影描边。

## 有意保留

以下命中是复查后确认的"有理由的选择"，不是待修的 slop：

- **圆形**：开关滑块、spinner、状态点。圆形是这些控件的功能形状，且没有 halo、脉冲或发光。
- **`.sss-link:hover` 下划线**：这是文字链接，不是装饰性强调。
- **LaTeX 的 `\overline` 与 `font-family:monospace`**：属于公式排版，不是 UI 里的 kicker / 终端 cosplay。
- **README 许可证行的 `©`**：扫描器的 emoji 规则会把它当成 emoji，实际是版权符号。
